# Roadmap

## v0.1 — каркас (текущая версия)
- [x] Модели, хранилище, сервисы
- [x] AI Tutor с офлайн-режимом
- [x] REST API и тесты ядра

## v0.2 — пользователи и данные
- [ ] Аутентификация (JWT / OAuth) и изоляция данных по пользователям
- [ ] SQLite → PostgreSQL через SQLAlchemy + Alembic
- [ ] Загрузка PDF/DOCX/PPTX и извлечение текста

## v0.3 — умнее
- [ ] Адаптивные тесты: сложность по истории ответов
- [ ] Планы, пересчитываемые по результатам тестов
- [ ] Морфологический анализ русского текста (pymorphy3)
- [ ] Стриминг ответов AI Tutor (SSE)

## v0.4 — клиенты
- [ ] Веб-интерфейс (React/Next.js)
- [ ] Календарная синхронизация дедлайнов (iCal / Google Calendar)
- [ ] Напоминания (email / Telegram)
